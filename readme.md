# D Shawarma Station POS

A point-of-sale application for managing shawarma shop billing and operations.

## Project Structure

- `client/` — React frontend built with Vite.
- `server/` — Node.js and Express backend.
- MongoDB — application database.

## Features

- User authentication
- Dashboard
- Billing and order creation
- Order history
- Menu and category management
- Sales reports
- Shop settings
- Receipt printing

## Requirements

- Node.js and npm
- MongoDB connection
- Environment variables configured locally
